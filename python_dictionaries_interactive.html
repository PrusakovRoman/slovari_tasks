Раздел 01 · 10 минут

Что такое словарь

Список хранит элементы по номерам (индексам). Словарь хранит пары ключ → значение. Например, имя ученика — ключ, балл — значение.

scores = {'Anna': 80, 'Max': 75}
print(scores['Anna'])  # 80

Ключи уникальны: два одинаковых ключа не могут существовать одновременно. Значения могут совпадать. Пустой словарь создаётся как d = {}. Числа и строки могут быть ключами.

Добавляем и изменяем

d['cat'] = 7

Раздел 03 · 15 минут

Ключи, значения и перебор

По умолчанию цикл for по словарю перебирает ключи. По ключу можно получить значение: d[key]. 

d = {'a': 10, 'b': 20}
for key in d:
    print(key, d[key])

print(list(d.keys()))    # ['a', 'b']
print(list(d.values()))  # [10, 20]
print(list(d.items()))   # [('a', 10), ('b', 20)]

Функции min(d) и max(d) ищут минимальный и максимальный ключ, а не значение. Для задачи с числовыми ключами можно использовать их сумму.

Раздел 04 · 20 минут

Словарь-счётчик

Один из самых полезных приёмов: ключ — элемент, значение — сколько раз он встретился. Перебираем строку по символам. Если ключа нет, создаём счётчик 0, затем увеличиваем на единицу.

s = 'banana'
d = {}
for c in s:
    if c not in d:
        d[c] = 0
    d[c] += 1
print(d)  # {'b': 1, 'a': 3, 'n': 2}

Почему нужна проверка? Выражение d[c] += 1 читает прежнее значение. Если ключа ещё нет, возникнет ошибка. Сначала создаём его со значением 0.

Раздел 05 · 10 минут

Сортировка по ключам

Метод items() возвращает пары (ключ, значение). sorted(...) сортирует пары по первому элементу — ключу, а dict(...) собирает их обратно в словарь.

d = {'n': 2, 'b': 1, 'a': 3}
d = dict(sorted(d.items()))
print(d)  # {'a': 3, 'b': 1, 'n': 2}

Для строчных латинских букв такой порядок будет алфавитным. В современном Python словарь сохраняет порядок вставки элементов.

Раздел 06 · 20 минут

Повторяющиеся идентификаторы

Теперь словарь будет хранить число предыдущих повторений исходного имени. Список ans сохранит результат в правильном порядке.

s = input().split()  # слова через пробел
ans = []
d = {}
for x in s:
    if x not in d:
        d[x] = 0
        ans.append(x)
    else:
        d[x] += 1
        ans.append(x + '_' + str(d[x]))
print(*ans)

split() делит строку на слова; append() добавляет элемент в список; str() превращает число в строку; print(*ans) печатает элементы списка через пробел. Первое появление остаётся без суффикса, второе получает _1, третье — _2.

В этой учебной задаче считаем, что исходные имена не конфликтуют с именами, полученными после добавления суффиксов.
